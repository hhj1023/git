# test_project

基于 pytest 的接口自动化测试项目。

## 项目结构

```
test_project/
├── run.py          # 测试入口
├── testcases/      # 测试用例
├── utils/          # 工具类
├── data/           # 测试数据
├── file/           # 测试用附件
└── report/         # 测试报告（已 gitignore）
```

## 运行

```bash
pip install pytest requests
python run.py
```
